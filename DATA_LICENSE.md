# CODE / IGS data terms

The repository's MIT license applies to software. It does not relicense CODE/IGS products or their numerical extracts.

Clock-bias assets are selected columns from public CODE MGEX final clock products. Please credit CODE and IGS, retain provider attribution, and follow the [IGS Data and Product Disclaimer and Terms of Use](https://igs.org/wp-content/uploads/2020/09/IGS-Data-and-Product-Disclaimer-and-Terms-of-Use-200805.pdf). Product headers identify the CODE reference [10.48350/185742](https://doi.org/10.48350/185742). Archive access information is at [IGS](https://igs.org/data/) and [CODE/AIUB](https://www.aiub.unibe.ch/download).

The extract converts clock biases from seconds to nanoseconds without imputation or interpolation. Its provenance is documented in `results/frozen/raw_products.json` and `docs/data.md`.
